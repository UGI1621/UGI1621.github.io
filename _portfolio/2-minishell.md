## Overview
bash의 동작을 참고해 직접 구현한 유닉스 셸입니다.
팀 프로젝트로 진행했으며, **프로세스 실행과 파이프라인 구현을 담당**했고 **명령어 파싱 구현에도 크게 참여**했습니다.

## Tech Stack
C · readline · Make

## 담당 역할
### 프로세스 실행 · 파이프라인 (메인 담당)
- `fork`, `execve`, `waitpid`를 이용한 외부 명령어 실행과 종료 상태(`$?`) 처리
- `pipe`, `dup2`를 이용한 다중 파이프라인(`cmd1 | cmd2 | cmd3`) 구현
- 입출력 리다이렉션(`<`, `>`, `>>`)과 heredoc(`<<`) 처리
- 사용하지 않는 파일 디스크립터 정리로 fd 누수와 프로세스 블로킹 방지

### 파싱 (공동 작업)
- 따옴표(`'`, `"`) 처리와 환경 변수(`$VAR`) 확장
- 토큰화와 문법 오류 검사

## 어려웠던 점과 해결
### 문서를 먼저 읽는 습관
bash 공식 문서를 충분히 읽지 않고 파싱부터 구현하다 보니 처리 순서와 방식이 여러 번 꼬였습니다.
결국 문서를 기준으로 구조를 다시 잡으면서, 구현 전에 명세를 먼저 읽는 습관이 중요하다는 것을 배웠습니다.

### fork 이후 파일 디스크립터 관리
프로세스를 fork한 뒤 어떤 fd를 언제 닫아야 하는지가 가장 헷갈렸습니다.
명령어들을 연결 리스트로 구성하고 **각 노드는 프로세스, 노드 사이의 연결은 파이프**라고 생각하니 fd의 흐름이 명확해졌고, 이 모델을 바탕으로 파이프라인을 구현했습니다.
