## Overview
고전적인 동시성 문제인 '식사하는 철학자 문제(Dining Philosophers Problem)'를 구현한 프로젝트입니다.
여러 철학자(스레드)가 포크(공유 자원)를 나눠 쓰면서 데드락이나 기아 상태 없이 동작하도록 만들었습니다.

## Tech Stack
C · pthread · Make

## 구현 내용
- 철학자마다 스레드를 하나씩 만들고, 포크는 뮤텍스로 보호
- 데드락을 피하기 위한 포크 획득 순서 설계
- 모니터링으로 철학자의 사망 여부를 시간 안에 감지
- 공유 데이터 접근을 뮤텍스로 보호해 데이터 레이스 방지

## 어려웠던 점과 해결
### 뮤텍스 개념 이해
처음에는 뮤텍스 개념을 이해하기 어려웠습니다.
뮤텍스를 **포크가 들어 있는 상자**라고 생각하고, 상자를 열었는데 포크가 없으면 다시 내려놓는 방식으로 정리하니 동작을 이해할 수 있었습니다.

### 타이밍 문제 (남은 과제)
`usleep` 위치를 적절히 정하지 못해 출력이 밀렸고, 출력에도 뮤텍스를 걸어 둔 탓에 죽지 않아야 할 철학자가 죽는 상황이 발생했습니다.
평가는 통과했지만 이 문제를 완전히 해결하지는 못했습니다. 스레드 간 대기 시간 조절과 출력 잠금이 타이밍에 주는 영향을 더 세밀하게 다뤄야 한다는 점을 배웠습니다.
