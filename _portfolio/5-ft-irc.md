## Overview
IRC(Internet Relay Chat) 프로토콜을 따르는 채팅 서버를 C++98로 구현한 프로젝트입니다.
실제 IRC 클라이언트로 접속해 여러 사용자가 채널에서 대화할 수 있습니다.
팀 프로젝트로 진행했으며, **소켓 통신과 이벤트 루프 등 서버 코어 구현을 담당**했습니다.

## Tech Stack
C++98 · POSIX Socket API · poll() · Make

## 담당 역할: 서버 코어
### 소켓 · 이벤트 루프
- `socket`, `bind`, `listen`, `accept`로 서버 소켓 생성과 클라이언트 연결 수락
- `poll()` 기반 이벤트 루프 하나로 여러 클라이언트의 입출력을 동시에 처리

### 연결 관리 · 비블로킹 I/O
- `recv`/`send`에 `MSG_DONTWAIT` 플래그를 주어 비블로킹으로 입출력해, 한 클라이언트 때문에 서버 전체가 멈추지 않도록 처리
- 클라이언트 접속·종료 시 파일 디스크립터와 사용자 정보 정리

### 메시지 버퍼링
- TCP 특성상 메시지가 잘리거나 여러 개가 붙어서 도착하는 문제를 클라이언트별 버퍼로 처리
- 버퍼를 원형 큐(circular queue)로 구현해, 처리한 메시지를 지울 때 남은 데이터를 앞으로 옮기는 복사 없이 재사용
- `\r\n` 단위로 완성된 메시지만 명령 처리부로 전달

## 어려웠던 점과 해결
### 너무 큰 입력의 처리 방식
IRC 문서를 참고해 메시지 버퍼 크기를 고정했는데, 버퍼보다 큰 입력이 들어왔을 때 어떻게 처리할지를 두고 팀원과 의견 차이가 컸습니다.
여러 번 논의한 끝에 팀원의 의견대로 **해당 클라이언트의 연결을 끊는 방식**으로 결정했고, 이 과정에서 서로의 근거를 듣고 합의하는 방법을 배웠습니다.
minishell에서 문서를 먼저 읽는 습관을 들인 경험이 명세를 근거로 논의하는 데 큰 도움이 되었습니다.
